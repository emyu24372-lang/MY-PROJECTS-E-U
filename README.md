
# MY-PROJECTS-E-U
This is where you will find my projects .
This project is a 3.5 mm jack-to-USB Type-C adapter that can be plugged into a phone or any other device with a Type-C port.
I was inspired by some commercially available models and designed it with the intention of using it mainly for IEM  headphones .
